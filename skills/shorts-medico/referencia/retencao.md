# Metas de retenção (medidas em Shorts reais; o medir.py confere as que dá para medir no arquivo)

| medida | meta | de onde |
|---|---|---|
| cabeça no quadro 0 | 37–47% da altura da tela | rosto grande já reagindo, título escrito em cima |
| imagem forte | em até 1 s | o pior vídeo mostrava a ideia em 1,9 s |
| mudanças de enquadramento nos 3 primeiros s | 2–3, cada uma numa palavra forte (`^palavra`) | |
| coisas novas na tela | ~13 a cada 10 s | gringos 13,2 · antes 4,0 · depois 12,8 |
| rosto em close | 9–46% (aqui 25–55%: autoridade do médico) | |
| som entre as falas | 3,5–5,8 dB abaixo da voz, nunca silêncio | |
| duração | 50–57 s | |
| fim | comentário de uma palavra + loop para o começo | 2 → 2.800 comentários |
| quadros parados | ≤ 30%, maior trecho ≤ 1,6 s | regra da motion-graphics-v3 |

O que NÃO fez diferença: 60 fps, tamanho/posição da legenda, velocidade da fala, volume geral.

## Depois de publicar (48 h)
1. "Continuaram assistindo" ≥ 75–80% → senão, os 3 primeiros segundos.
2. Duração média ~90–95% do vídeo → senão, cortar frase que não acrescenta / emendar o fim no começo.
3. Curva: despenca no começo = gancho · degrau no meio = resposta cedo ou momento chato · desce aos poucos = falta nova
   curiosidade · quedas espalhadas = ritmo · plana >100% = repetir a receita.
Mude UMA coisa por vez no próximo vídeo. Não apague, não reposte, não troque título/capa antes de 48 h.
Na publicação: título ≤ 50 caracteres; capa em série (mesmo layout); vídeo relacionado = último Short; horário fixo;
responder os primeiros comentários e fixar o "Comenta PALAVRA 👇"; o mesmo MP4 no Reels e no TikTok.
