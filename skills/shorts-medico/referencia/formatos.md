# Formatos que prendem (filtrados pelo CFM) e como escrever

| formato | estrutura | exemplo de 1ª frase (= título da capa) |
|---|---|---|
| Mito × verdade | crença comum → carimbo → por quê → o que fazer | "Pressão alta quase nunca dá sintoma." |
| Lista com o melhor no fim | "3 sinais…" → 1, 2 → "o terceiro quase ninguém percebe" | "3 sinais de que seu cansaço não é normal." |
| O erro que eu mais vejo | caso típico do consultório (sem identificar) → por que acontece → como evitar | "O erro que eu mais vejo no consultório é esse." |
| E se…? (sem pânico) | pergunta → o que acontece no corpo em passos → virada | "E se você parasse de tomar café por 7 dias?" |
| O que acontece no seu corpo quando… | gatilho → 3 etapas com tempo → conclusão útil | "O que acontece no seu corpo quando você dorme 5 horas." |
| Número que surpreende | dado com fonte → escala (Brasil/mundo) → o que significa para você | "Quase metade de quem tem pressão alta não sabe." |

Fora (CFM): alguém em perigo/medo ("isso pode te matar"), antes e depois de paciente, "o melhor tratamento",
promessa de resultado, remédio ou produto por nome.

## Roteiro
- 110–140 palavras faladas (45–57 s). Frases curtas. Uma ideia por frase.
- Gancho: o título é a 1ª frase; o rosto já está em close; algo acontece no 1º segundo.
- Escalada: quando uma pergunta fecha, abra outra ("mas o detalhe é outro", "e o terceiro é o mais estranho").
- A resposta prometida no gancho fica para o fim.
- Uma frase que só esse médico diria (experiência dele) — passa no teste da troca e constrói autoridade.
- Utilidade para compartilhar: "manda para quem…".
- Fim: convite para contar a própria experiência ("comenta aqui em que situação você já viu isso") + emenda no
  começo para o loop. "Comenta PALAVRA" só se a pessoa pedir.
- Nunca: pedido de inscrição, "oi, gente", apresentação longa, "link na bio" no meio.
